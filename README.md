# Python Learning Repository

A collection of Python notebooks, small applications, data-analysis exercises and scientific experiments created while learning, prototyping and exploring different technical topics.

This is intentionally a mixed learning and experimentation repository rather than a single production application. The projects are kept together as a record of practical work and ongoing exploration.

## Repository structure

### [`learning-projects/`](learning-projects/)

Assorted notebooks and exercises covering topics such as:

- data analysis and exploratory data work;
- machine learning, including classification and regression;
- economic and financial analysis;
- SQL and data exploration;
- miscellaneous experiments with datasets and algorithms.

The notebooks are at different stages of development. Some are learning exercises or prototypes, and not every notebook is polished or production-ready.

### [`Personal Finance Tracker/`](Personal%20Finance%20Tracker/)

A more focused personal project for recording and working with income and expense data. It includes notebooks, a small Python helper module and example CSV data.

### [`Pyhton_AFM_Bacterias/`](Pyhton_AFM_Bacterias/)

Exploratory scientific work related to atomic force microscopy (AFM) and bacteria, including notebooks for elastic and plastic modelling. This material represents experimentation and analysis in progress; it is not presented as a validated scientific package.

## Project maturity

Projects in this repository have different maturity levels:

- learning exercises;
- exploratory notebooks;
- small prototypes;
- more focused personal projects.

That variation is intentional. Projects that grow into more mature or independently maintained work may move to dedicated repositories later.

## Working with the repository

The notebooks and projects are preserved as practical learning material. Read the relevant notebook or project files before making assumptions about their intended use, inputs or environment. There is currently no shared dependency manifest because the projects explore different topics and may require different tools.

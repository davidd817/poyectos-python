# Repository guidance

- This repository is a mixed personal learning and experimentation space containing notebooks, small applications and exploratory scientific work.
- Do not casually rewrite notebooks or project code. Preserve the existing folder structure unless a change is explicitly requested.
- Do not infer or invent a project's maturity, validation status or production readiness.
- Keep all repository-facing documentation in English. Notebook contents and application UI may remain in their original language unless explicitly requested otherwise.
- Inspect the repository before modifying it, and keep changes focused on the stated task.
- Avoid unnecessary dependencies, tests added only for appearance, and overengineering.
- Do not create commits or push changes automatically.
